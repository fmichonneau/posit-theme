# posit-theme

A Claude Code theme drawn from the Posit brand palette (`_brand.yml`): ink,
navy and slate for text and panels, and blue, orange, green, amber and teal
for the accent, danger, success, warning and pro roles. It covers both light
and dark mode, with a tighter dark-mode surface ramp kept close to the page
color so role colors (git status, syntax, buttons) stay readable against
cards and panels. The theme is applied automatically: once installed, a
`session.start` hook sets it for every new session, with no picker or
manual step needed.

## Install

```
/plugin install posit-theme --marketplace fmichonneau/posit-theme
```
